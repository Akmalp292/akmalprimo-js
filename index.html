Enter a number to see the result.

How to use

  1. Enter a number. Whole numbers only, 0 or greater.
  2. Read the result. It updates while you type.
  3. Copy it if needed. The result and the reason are copied as two lines.

This method involves division by 2, 3, followed by divisions with divisors in the form of 6k - 1 and 6k + 1 till the square root of that number. The first divisor encountered is the smallest factor. Larger numbers are tested using the Miller-Rabin test.

Example: 77 → not divisible by 2 or 3 → try 5 (no), 7 (yes) → 77 = 7 × 11, so it is not prime.
